# Tangelo App Branding Guide

This document contains all the necessary branding and style information to create external materials like a pitch deck or marketing content that aligns with the Tangelo app's visual identity.

---

## Color Palette

The color scheme is designed to be warm, sophisticated, and loving.

| Role        | Name           | Hex Code  | CSS HSL Variable        |
|-------------|----------------|-----------|-------------------------|
| **Primary** | Muted Coral    | `#F08080` | `0 79% 75%`             |
| **Background**| Light Coral    | `#F8D7D7` | `0 71% 91%`             |
| **Accent**  | Dusty Rose     | `#D2691E` | `25 75% 47%`            |

---

## Typography

The font pairing creates an elegant yet readable feel. Both fonts are available for free on Google Fonts.

-   **Headlines & Titles:** `Playfair Display` (Serif)
    -   *Use for:* Main titles, section headers, and the logo.
    -   *Feel:* Elegant, high-end, classic.

-   **Body Text & UI Elements:** `PT Sans` (Sans-serif)
    -   *Use for:* Paragraphs, descriptions, button text, and other UI elements.
    -   *Feel:* Clean, modern, and highly readable.

---

## Logo

The logo is the word "Tangelo" written in the headline font, **Playfair Display**. It should typically be displayed in the **Primary (Muted Coral)** color.
