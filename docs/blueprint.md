# **App Name**: Tangelo

## Core Features:

- Interactive Dashboard: Interactive dashboard with a personalized wedding planning checklist, calendar sync, and countdown timer.
- Vendor Marketplace: Vendor marketplace allowing users to search and filter vendors by category, price, location
- AI Vendor Suggestions: AI-powered vendor recommendation tool to suggest vendors based on user budget, location, preferences, and trending styles using a reasoning tool.
- Smart Budgeting: Smart budgeting tool providing a visual breakdown of expenses (via charts), automated expense tracking linked to tasks/vendors, and alerts for budget overspending.
- Guest List Management: Guest list management, facilitating easy uploading via CSV, RSVP tracking, dietary preferences management, and seating arrangement tools.
- Push Notifications: Notification system offering push notifications and in-app alerts for key milestones.

## Style Guidelines:

- Primary color: Muted coral (#F08080) to evoke feelings of love, warmth, and sophistication without being overtly cliché.
- Background color: Very light desaturated coral (#F8D7D7) to maintain warmth while ensuring elements pop.
- Accent color: Dusty rose (#D2691E), a darker, muted analogous tone, providing contrast while aligning with overall palette of love and sophistication.
- Font pairing: 'Playfair' (serif) for headlines, to give an elegant, high-end feel, and 'PT Sans' (sans-serif) for body, ensuring readability in longer texts.
- Elegant, custom-designed icons representing each vendor category and planning task to provide visual guidance.
- Clean and intuitive layout, designed with a mobile-first approach. Focus on easy navigation and visual clarity to avoid overwhelming users.
- Subtle transition animations and interactive elements to create an engaging and seamless user experience.
